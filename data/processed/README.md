# Processed DashBot Training Data

Generated by:

```powershell
python scripts/prepare_data.py
```

This folder contains cleaned CSV files derived from the 27-file Vega training manifest in `data/raw/vega_27_manifest.txt`.

Cleaning rules:

- normalize column names to lowercase snake_case;
- remove all-null columns;
- remove columns with more than 45% missing values;
- coerce numeric-looking text columns to numbers;
- drop uninformative constant columns;
- drop high-cardinality ID-like text columns;
- keep at most 10 columns per dataset, matching the DashBot paper's max-column modeling assumption;
- fill numeric missing values with median;
- fill categorical missing values with mode;
- drop duplicate rows;
- cap each dataset at 10,000 rows.
